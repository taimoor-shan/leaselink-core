# Student Rental Housing Platform

WordPress plugin for connecting students with landlords for rental housing.

## 🚀 Quick Start with Antigravity IDE

### 1. Initial Setup

```bash
# Clone and open in Antigravity
git clone [your-repo]
cd student-rental-platform

# Antigravity will auto-detect .antigravity/project.yaml
```

### 2. Start Development

Antigravity AI will automatically:

- ✅ Read `.antigravity/context.md` for instructions
- ✅ Reference `docs/REQUIREMENTS.md` for business logic
- ✅ Follow WordPress coding standards
- ✅ Apply security best practices

### 3. Example Prompts

**Create Database Schema:**

```
"Read docs/REQUIREMENTS.md Section 2.2 and create the
wp_rental_applications table with all indexes"
```

**Build Feature:**

```
"Following REQUIREMENTS.md Section 3.2, implement the
Application Workflow class with state validation and
email notifications"
```

**Generate API Endpoint:**

```
"Create the listings search endpoint from docs/API_SPEC.md
with geolocation support and caching"
```
